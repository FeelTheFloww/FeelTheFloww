## 🔬 Featured projects

### Quantitative Finance & ML
- **[black-scholes-empirical-study](https://github.com/FeelTheFloww/black-scholes-empirical-study)** — Option pricing and implied volatility pipeline on real market data: Brent solver, put–call parity checks, volatility smile visualization.
- **[heston-model](https://github.com/FeelTheFloww/heston-model)** — Heston stochastic volatility model: Monte Carlo pricing, implied volatility smile reconstruction, parameter sensitivity and calibration workflow.
- **[market-stress-regime-detection](https://github.com/FeelTheFloww/market-stress-regime-detection)** — ML classification of market stress regimes on 13 years of SPY data, with walk-forward validation.
- **[adl-ethics](https://github.com/FeelTheFloww/adl-ethics)** — Research project: comparing DPO, RLHF (PPO) and RAG for the ethical alignment of small LLMs on the ETHICS benchmark (Qwen2.5-1.5B, LoRA, TRL).

### Software & DevOps Engineering
- **[monitoring-server](https://github.com/FeelTheFloww/monitoring-server)** — FastAPI system-monitoring server (CPU/RAM/disk/network metrics, log parsing), fully containerized with CI/CD and automated Docker Hub releases. *(team project)*
- **[monitoring-dashboard](https://github.com/FeelTheFloww/monitoring-dashboard)** — Real-time web dashboard consuming the monitoring API. *(team project)*
- **[deployment-puller](https://github.com/FeelTheFloww/deployment-puller)** — Lightweight watchtower-style container that auto-redeploys an app when a new Docker image is published.
- **[tsp-route-optimizer](https://github.com/FeelTheFloww/tsp-route-optimizer)** — Travelling Salesman Problem solver: exact (Branch & Bound) and heuristic (2-opt, genetic) algorithms behind a Flask API + Leaflet map UI. *(team project)*
